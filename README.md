# campaign-site

One-page post-election thank-you site for helenafoulkes.com.

- `index.html`: the page (header, "Thank you, Rhode Island" hero, donate section, footer)
- `assets/site.css`: styles (campaign blue/navy/green, Barlow Semi Condensed + Montserrat)
- `assets/img/`: Helena cutout (hero) and park photo (blurred hero background)

Static HTML/CSS, no build step. Host on GitHub Pages from `main` (root).
Remove the `noindex` meta tag in `index.html` before go-live.
